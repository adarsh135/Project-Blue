Project Blue

Your own agentic AI,
on your own server.

Blue is a self-hosted assistant with the plumbing that matters: real accounts, revocable sessions, hashed API keys, an agent loop with tools, durable memory and a per-user recent-search history. No key required to start — plug in OpenAI, Anthropic, Gemini or a local Ollama when you want a bigger brain.

🔎 Recent searches

Every search Blue runs is written to your account with its provider, result count and timestamp. Run one directly, pin the useful ones, or clear the noise.

🧠 Memory

Durable facts Blue keeps about you. The agent writes these when you say "remember…", and they're injected into every future system prompt.

🧰 Tools

Tools are the difference between a chatbot and an agent. Blue decides when to call these; you decide which are available.

⚙️ Model

Pick the brain behind the agent loop. Everything else — auth, sessions, memory, search history — stays identical.

🔌 Configured providers

Providers are enabled by environment variables on the server. Add a key to .env and restart — no code changes needed.

OPENAI_API_KEY=sk-…        # OpenAI or any compatible endpoint
ANTHROPIC_API_KEY=sk-ant-…  # Claude
GEMINI_API_KEY=…            # Gemini
OLLAMA_BASE_URL=http://localhost:11434   # local models, no key
TAVILY_API_KEY=…            # better web search (optional)

👤 Profile

Your identity for this server.

🔑 Change password

Passwords are hashed with scrypt (N=32768) and a per-user salt. Changing it signs out every other device.

🧵 Sessions 0

Each sign-in is a separate, revocable session. Revoke anything you don't recognise.

🔐 API keys

Machine credentials for scripts and integrations. The secret is shown once; only a SHA-256 hash is stored.

Use it as a bearer token:

curl -s http://localhost:4000/api/chat \
  -H "Authorization: Bearer blue_sk_…" \
  -H "Content-Type: application/json" \
  -d '{"content":"search for the latest SQLite release"}'

📜 Auth activity

Recent credential events on this account (logins, failed attempts, key and session changes).

⚠️ Danger zone

Deleting the account erases every chat, search, memory and key. This cannot be undone.
